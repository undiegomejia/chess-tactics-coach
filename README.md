# Chess Tactics Coach

An agentic chess tactics coach: upload PGN games, get Stockfish analysis, and
receive AI-powered explanations of *why* a move was a mistake — powered by
Claude acting as an agentic coach with access to real chess-engine tools.

## ✅ Phase 1 — MVP (Complete)

Core CRUD routes talking directly to the database and Stockfish engine.
No separation of concerns by design — proves the end-to-end loop works
before introducing architecture.

**Endpoints delivered:**
- `POST /games` — accept a PGN string, validate, and store it
- `GET /games` — list stored games (id, white, black, result)
- `GET /games/{id}` — retrieve a single game
- `GET /games/{id}/analysis` — run Stockfish on all positions, return evaluations
- `GET /health` — health check endpoint

## ✅ Phase 2 — Hexagonal Architecture (Complete)

Routes refactored into a clean Ports & Adapters structure. The domain layer
is pure Python — no SQLAlchemy, no Stockfish, no Pydantic.

### Architecture

```
┌─────────────────────────────────────────┐
│  API Layer  (app/main.py)               │
│  HTTP/JSON translation only             │
└───────────────┬─────────────────────────┘
                │
┌───────────────▼─────────────────────────┐
│  Use Cases  (app/use_cases/)            │
│  create_game · list_games · analyze_game│
└───────────────┬─────────────────────────┘
                │
        ┌───────┴───────┐
        │               │
┌───────▼──────┐ ┌──────▼────────────────┐
│  Ports       │ │  Ports                │
│  GameRepo    │ │  ChessEngine          │
│  Port        │ │  Port                 │
└───────┬──────┘ └──────┬────────────────┘
        │               │
┌───────▼──────┐ ┌──────▼────────────────┐
│  Persistence │ │  Chess Engine         │
│  Adapter     │ │  Adapter              │
│  (SQLAlchemy)│ │  (Stockfish)          │
└──────────────┘ └───────────────────────┘
```

### Key files delivered

| File | Role |
|------|------|
| `app/domain/entities.py` | `GameEntity`, `EvaluationEntity` — pure dataclasses |
| `app/domain/ports.py` | `GameRepositoryPort`, `ChessEnginePort` — Protocol interfaces |
| `app/adapters/persistence.py` | `SQLAlchemyGameRepository` — only place SQLAlchemy lives |
| `app/adapters/chess_engine_adapter.py` | `StockfishEngineAdapter` — only place Stockfish lives |
| `app/use_cases/game_use_cases.py` | `create_game`, `list_games`, `fetch_game`, `analyze_game` |
| `tests/adapters/` | Adapter-level tests with real SQLite, fake engine |
| `tests/use_cases/` | Use-case tests with fake repository and fake engine |

## ✅ Phase 3 — Coach Logic (Complete)

Adds a fully agentic coaching layer: deterministic mistake detection
(pure Python, no AI) layered with a Claude-powered adapter that explains
*why* each mistake matters and what the best continuation was.

### New domain entities (planned)

```python
@dataclass
class Mistake:
    move_number: int
    player: str          # "white" | "black"
    fen_before: str
    fen_after: str
    eval_before: int     # centipawns
    eval_after: int
    move_played: str     # UCI notation

@dataclass
class Explanation:
    mistake: Mistake
    text: str            # generated by Claude
    best_move: str       # engine's top choice
```

### New ports (Complete)

```python
class CoachingPort(Protocol):
    def explain(
        self, game: GameEntity, mistakes: list[Mistake]
    ) -> list[Explanation]: ...
```

### New use cases (Complete)

| Use Case | What it does |
|----------|-------------|
| `detect_mistakes` | Pure Python — walks evaluations, flags eval swings above threshold |
| `explain_mistakes` | Orchestrates: detect → hand to `CoachingPort` → return explanations |

### New adapter (Complete)

`ClaudeCoachAdapter` — the **only** file that imports the Anthropic SDK.
Takes a `ChessEnginePort` as a constructor dependency so Claude can call
`get_best_move` as a real tool during the agentic loop.

### New endpoint (Complete)

`GET /games/{id}/coaching` — thin route, same pattern as `/analysis`.

### Testing strategy

- **Unit tests:** `FakeCoachingPort` returns canned explanations — free, fast, deterministic
- **Integration tests:** Real Anthropic API calls, opt-in only (cost + non-determinism)

## Setup

### 1. Python environment

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Install Stockfish

- **macOS**: `brew install stockfish`
- **Ubuntu/Debian**: `sudo apt-get install stockfish`
- **Windows**: download from https://stockfishchess.org/download/

### 3. Configure environment

```bash
cp .env.example .env
# Required:
#   STOCKFISH_PATH — absolute path to the stockfish binary
#   ANTHROPIC_API_KEY — your Anthropic key (Phase 3, optional for now)
```

### 4. Verify Stockfish is reachable

```bash
python scripts/check_stockfish.py
```

### 5. Run the API

```bash
uvicorn app.main:app --reload
```

Visit http://127.0.0.1:8000/docs for the interactive OpenAPI UI.

### 6. Run tests

```bash
pytest                        # all tests (unit + integration, no API calls)
pytest tests/use_cases/       # use-case layer only
pytest tests/adapters/        # adapter layer only
```
